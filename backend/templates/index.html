Network Protocol Forensic Handbook

Core protocol specifications, packet structure standards, and security dissection patterns.

Layer 2 (Data Link) Ethernet & ARP

Address Resolution Protocol (ARP)

Binds Layer 3 IP network addressing to Layer 2 physical MAC addresses. The sender broadcasts Who has IP? Tell Me (Opcode 1), and the target machine responds with IP is at MAC (Opcode 2).

Layer 7 (Application) UDP Port 53

Domain Name System (DNS)

Resolves human-friendly domain names (e.g. example.com) into IP addresses (A/AAAA records). Unencrypted DNS over standard UDP 53 exposes queries to network eavesdropping.

Layer 4 (Transport) TCP Handshake

TCP 3-Way Handshake & Reliability

Reliable stateful communication is established through:
• SYN: Client requests connection and establishes Initial Sequence Number.
• SYN-ACK: Server acknowledges and sends its Initial Sequence Number.
• ACK: Client acknowledges; stream is ready for payload transmission.

Layer 7 (Security) TLS 1.2 / 1.3

Transport Layer Security (TLS)

Establishes cryptographic tunnel. The Client Hello proposes SNI and cipher suites. The Server Hello confirms cryptographic parameters and validates identity via certificates.

Cleartext Risk HTTP Port 80

HTTP vs HTTPS Security Audit

Plain HTTP transmits headers, cookies, and payloads in cleartext. HTTPS wraps HTTP requests inside a TLS encrypted envelope, preventing snooping and tampering.

Termination FIN vs RST

Connection Teardown vs Abrupt Resets

• FIN-ACK: Graceful bidirectional connection closing.
• RST (Reset): Abrupt termination sent when connecting to a closed port, firewall rejection, or unexpected socket drop.
