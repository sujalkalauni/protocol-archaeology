Network Protocol Reference

Quick handbook of common networking protocols and headers.

ARP (Layer 2)

Address Resolution Protocol

Resolves Layer 3 IP addresses into Layer 2 physical MAC addresses on local subnets.

DNS (Layer 7)

Domain Name System

Translates human-readable domain names into IP addresses. Standard DNS runs over unencrypted UDP 53.

TCP Handshake (Layer 4)

Connection Establishment

Establishes reliable state via SYN (Initiate), SYN-ACK (Acknowledge and Reply), and ACK (Confirm).

TLS (Layer 7)

Transport Layer Security

Negotiates cryptographic ciphers and encrypts application data payloads to prevent eavesdropping.
